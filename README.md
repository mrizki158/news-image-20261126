# Thursday 26 November 2026 in one picture

One image that sums up the world news of Thursday 26 November 2026: 50 stories
across 10 regions and 15 fields, drawn by a program with PIL shapes only —
no photos. Three lead stories (Kim Jong Un's tactical-nuclear push, Asia's
market rebound, the Thanksgiving nor'easter), ten illustrated tiles, a UTC
strip, a numbers strip, a world map with pins, a 37-story index and a
date-check box stating what was deliberately left out as earlier news and
what has not happened yet.

## How it works

`main.py` (Python 3.13 standard library only) copies `entry.png` to the output
directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). `build_image.py` is the
program that drew `entry.png` (1024×1024 PNG, Pillow); it is not needed at run
time. Running `main.py` twice writes byte-identical output.
